ATM Java Project

A simple ATM simulation project built using Java.

Features

- Check account balance
- Deposit money
- Withdraw money
- ATM menu system
- Basic bank account management

Technologies Used

- Java
- Object-Oriented Programming
- Scanner for user input

Project Structure

- "ATM.java" — Handles ATM menu and operations
- "BankAccount.java" — Manages account details and transactions
- "Main.java" — Starts the application

How to Run

Compile the Java files:

javac *.java

Run the program:

java Main

Purpose

This project was created to practice Java fundamentals, OOP concepts, classes, methods, and user input handling.
